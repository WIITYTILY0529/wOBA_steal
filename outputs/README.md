# Outputs

`tables/` holds the result CSVs produced during the research.

- `adj1.csv`: Earlier version of the adjusted-wOBA calculation
- `final.csv`: Current final merged table (produced by `scripts/wOBA_steal_adj.py`)
- `wOBA_steal.csv`: Results of the early, simplified adjustment
- `wOBA_steal_adj_all.csv`: Adjusted-wOBA calculation with all intermediate columns
